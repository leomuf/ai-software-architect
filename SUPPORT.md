# Support

AI Software Architect is published and supported under the **AUTOSOFT
Engineering** brand by **XAVIER MUFFATO LTDA**.

## Questions and Bug Reports

Use the repository's
[GitHub issue tracker](https://github.com/leomuf/ai-software-architect/issues) for:

- installation or update problems;
- hook activation questions;
- hook activation or lifecycle failures;
- incorrect or confusing architecture behavior; and
- documentation improvements.

Before opening an issue, search for an existing report.

## Information to Include

Provide only non-sensitive diagnostic information:

- AI Software Architect plugin version;
- Codex version;
- Windows version and architecture;
- whether the package came from a GitHub release or personal marketplace;
- whether the hooks were reviewed and activated;
- the skill invocation used;
- the expected and actual behavior;
- relevant sanitized error messages; and
- whether uninstall succeeded on the first attempt.

Never post credentials, confidential source code, private repository content, hidden
reasoning, personal plugin-cache contents, or sensitive filesystem paths.

## Security Vulnerabilities

Do not report vulnerabilities through a public issue. Use the private process in
[`SECURITY.md`](SECURITY.md).

## Current Support Scope

The latest released minor version receives support. The current packaged runtime
targets Windows x86-64. GitHub
Copilot, Claude Code, Google Antigravity, and other coding-agent adapters are not yet
implemented.

For questions that are unsuitable for a public issue, contact
[info@autosoft-engineering.de](mailto:info@autosoft-engineering.de). Response times
are best-effort unless a separate written support agreement applies.
